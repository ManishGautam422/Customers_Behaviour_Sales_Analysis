# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using Python, Pandas, and Matplotlib. The analysis explores customer demographics, purchasing patterns, product categories, seasonal trends, payment methods, subscription status, promotions, shipping preferences, and purchase frequency.

## 🎯 Objectives

- Perform Exploratory Data Analysis (EDA)
- Understand customer purchasing patterns
- Analyze product category performance
- Identify seasonal shopping trends
- Analyze payment and shipping preferences
- Study subscription and promotional behavior
- Generate meaningful business insights

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- CSV Dataset

## 📊 Key Analysis

- Customer Age Distribution
- Purchase Amount Distribution
- Purchases by Category
- Purchases by Season
- Customers by Gender
- Payment Method Preferences
- Subscription Analysis
- Shipping Type Analysis
- Purchase Frequency
- Product and Location Analysis

## 💡 Key Insights

The analysis provides insights into customer demographics, popular product categories, purchasing behavior, payment preferences, seasonal trends, and customer engagement.
